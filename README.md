# Leap Year Checker

## Description

This Python program checks whether a given year is a leap year.

A year is considered a leap year when it is divisible by 400, or when it is divisible by 4 but not divisible by 100.

## Concepts Used

* Functions
* Conditional Statements
* Boolean Values
* Modulus Operator
* Logical Conditions
* User Input
* Type Conversion
* Exception Handling

## Technologies

* Python 3

## How to Run

```bash
python leap_year.py
```

## Sample Output

```text

        LEAP YEAR CHECKER
================================
Enter a year: 2024

2024 is a Leap Year.
February has 29 days.
```
